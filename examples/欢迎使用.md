# 让阅读，回到内容本身。

欢迎使用 **MdView**。一份文档，一片安静的阅读空间。

打开你的 Markdown，或者直接把文件拖到这里。代码、表格与思路，都能清晰呈现。

> 专注于内容，其余交给阅读器。文件在本地读取，无需上传。

## 开始阅读

- 选择菜单 **文件 → 打开 Markdown…**，或按 `Ctrl + O`。
- 将 `.md` / `.markdown` 文件拖入窗口。
- 点击左侧目录，快速跳转到感兴趣的章节。
- 文件更新后按 `Ctrl + R` 重新读取。

## 代码，也值得好好阅读

在代码围栏后标明语言，即可获得语法高亮。用代码块右上角的 **A− / A＋** 调整这一块代码的字号，点击百分比恢复默认。「复制」按钮始终保留原始代码。

点击 **单独查看**，在弹框中专注阅读代码，保留当前样式与字号。弹框内也支持 **Ctrl＋滚轮** 独立缩放，按 **Esc** 返回正文。

```javascript
const reader = {
  name: 'MdView',
  theme: 'light',
  focus: true
};

function greet(name) {
  // 从一份 Markdown 开始
  return `你好，${name}。今天读点什么？`;
}

console.log(greet(reader.name));
```

## 选一种舒服的配色

| 主题 | 适合的阅读时刻 |
| :--- | :--- |
| 浅色 | 清晰明快的日间阅读 |
| 深色 | 低亮度环境中的专注时刻 |
| 暖纸 | 柔和纸感，慢慢读一篇长文 |
| 跟随系统 | 随 Windows 外观自动切换 |

页面与代码配色同步切换。主题和字号会保留到下次启动。

按住 **Ctrl** 并向上滚动鼠标滚轮放大阅读字号，向下滚动缩小；也可使用顶部的 A− / A＋。

## 图片与链接

支持 Markdown 文件所在目录及其子目录中的相对路径图片，例如 `![截图](images/demo.png)`。

首版不加载网络图片、SVG 或文档目录外的图片。网页链接会在默认浏览器中打开。

## 快捷键

| 操作 | 快捷键 |
| :--- | :--- |
| 打开文档 | `Ctrl + O` |
| 重新读取 | `Ctrl + R` |
| 显示 / 隐藏目录 | `Ctrl + B` |
| 全屏 | `F11` |
